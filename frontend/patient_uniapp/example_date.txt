你是一名资深的全栈 UI/UX 工程师，请为“患者端智慧医疗系统”生成一个现代化、高级感、可直接运行的前端登录页面。

# 技术要求
- 使用 React + Tailwind CSS
- 使用 Vite 构建
- 页面需为单文件组件（方便 AI coding 工具直接生成）
- 风格参考：Apple + 腾讯医疗 + 阿里健康 的现代医疗科技风
- 页面必须具有高级感、真实商业产品感，而不是练习 Demo
- 必须适配 PC 与移动端（响应式设计）
- 页面动画使用 Framer Motion
- 图标使用 lucide-react
- 代码需结构清晰、可维护
- 所有组件必须完整可运行

# 页面整体风格
整体采用：
- 蓝白色医疗科技风
- 大面积留白
- 柔和阴影
- 半透明磨砂玻璃效果（glassmorphism）
- 圆角卡片
- 高级渐变
- 干净、可信赖、专业

主色调：
- Primary Blue: #2563EB
- Light Blue: #DBEAFE
- Accent Cyan: #06B6D4
- Background: #F8FBFF
- Text Dark: #1E293B

# 页面布局
采用左右分栏布局：

左侧（品牌展示区）：
- 医疗插画 / 科技感背景
- 系统 Logo
- 系统名称：
  “智慧医疗患者平台”
- Slogan：
  “让诊疗更高效，让健康更智能”
- 展示 3 个核心能力：
  1. AI 智能问诊
  2. 在线报告解读
  3. 诊后康复管理
- 卡片式信息展示
- 背景包含渐变光效、网格、模糊光斑

右侧（登录区域）：
- 登录卡片居中
- 毛玻璃效果
- 支持：
  - 手机号登录
  - 密码登录
  - 验证码登录切换
- 输入框：
  - 手机号
  - 密码 / 验证码
- “记住我”
- “忘记密码”
- 登录按钮
- 微信登录按钮
- Apple 登录按钮
- 注册入口

# 视觉细节要求
必须包含：
- 顶部柔和渐变背景
- 动态漂浮光球
- 登录按钮 hover 动效
- 输入框 focus 发光效果
- 页面加载淡入动画
- 卡片悬浮动画
- 背景微粒子效果（轻量即可）
- 高级阴影（不要廉价感）

# 交互要求
- 输入框校验
- 手机号格式校验
- 登录按钮 loading 状态
- 错误提示 toast
- 登录成功模拟跳转
- 表单切换动画
- hover 时按钮具有轻微上浮效果

# 页面顶部
顶部导航栏：
- Logo
- “首页”
- “健康服务”
- “在线问诊”
- “AI 医疗助手”
- “关于我们”

右上角：
- “联系客服”
- “帮助中心”

# 页面底部
Footer 包含：
- 医疗备案信息
- 隐私协议
- 用户协议
- Copyright
- 蓝白渐变分割线

# UI 高级感要求（非常重要）
避免：
- 低级渐变
- 廉价阴影
- 过于鲜艳颜色
- 拥挤布局
- 传统 bootstrap 风格

必须做到：
- 类似真实互联网医疗 SaaS 产品
- 类似高端 AI 医疗平台官网
- 有科技感
- 有呼吸感
- 有层次感
- 有视觉节奏

# 额外增强
请额外加入：
- 实时时间显示
- 今日天气卡片（静态模拟即可）
- 医疗数据浮动卡片（例如“今日在线医生 3245 位”）
- AI 智能助手悬浮按钮
- 页面进入动画
- SVG 科技线条背景

# 输出要求
- 直接输出完整 React 页面代码
- 不要解释
- 不要省略
- 保证代码可运行
- 默认导出组件
- 所有依赖均使用现代 React 写法
