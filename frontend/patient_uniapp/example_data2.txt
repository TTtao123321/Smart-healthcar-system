你是一名顶级 AI 产品 UI/UX 工程师，请为“智慧医疗患者端系统”设计并生成一个高端、现代化、可直接运行的“AI 在线医疗问诊聊天页面”。

# 技术要求
- 使用 React + Tailwind CSS
- 使用 Vite
- 单文件组件输出
- 使用 Framer Motion 实现动画
- 使用 lucide-react 图标
- 页面必须可直接运行
- 代码结构清晰
- 风格必须达到商业级 SaaS 产品标准

# 整体产品定位
这是一个：
“患者端 AI 智能医疗助手”

用户登录后：
- 与 AI 医疗助手对话
- 上传检查报告
- 获取报告解读
- 获得诊后康复建议
- 获取导诊建议

页面风格：
- 类似 ChatGPT / Claude / 腾讯元宝 / Notion AI 的高级极简风
- 但更加医疗科技化
- 蓝白色医疗主题
- 页面具有空间感和呼吸感
- 中间聚焦式布局

# 页面核心布局（非常重要）
不要采用 ChatGPT 那种全屏铺满聊天窗口。

必须采用：
“居中悬浮式 AI 问诊对话框”

布局结构：

┌───────────────────────┐
│ 顶部导航栏             │

# 对话框要求（重点）
聊天窗口：
- 宽度约 900px
- 高度约 75vh
- 位于页面正中央
- 圆角 32px
- 半透明磨砂玻璃效果
- 高级阴影
- 有轻微悬浮感
- 类似未来感 AI 控制台

聊天框不要占满整个屏幕。

页面四周必须保留大量留白。
